# 本地密码本

[English](README.md) | 中文说明

一个完全离线的安卓密码管理应用。所有数据都在本机用主密码加密保存，应用**不申请任何网络权限**。

## 功能

- **主密码进入** — 必须用主密码解锁；可选开启指纹解锁作为便捷方式。
- **加密存储** — 密码名称、账户、密码、子密码、备注以 AES-256-GCM 密文整体保存。
- **分组** — 按使用人或用途分组（如「父亲」「母亲」「工作」），列表支持按分组筛选与分区展示。
- **子密码** — 每条记录可再存一个密码，例如登录密码 + 支付密码。
- **随机密码生成** — 一键生成包含大小写字母、数字、符号的强随机密码。
- **密码强度** — 每个密码框下方实时显示强度。
- **自动锁定** — 空闲超时或切到后台后自动锁定。
- **剪贴板清理** — 复制的密码 30 秒后自动从剪贴板清除。
- **防截图** — `FLAG_SECURE` 阻止截屏与录屏。
- **不进备份** — 关闭系统备份与换机迁移，数据保存在 `noBackupFilesDir`。

## 安全设计

```
主密码 ──PBKDF2-HMAC-SHA256（600,000 次迭代，32 字节盐）──> KEK
                                                            │
                                            AES-256-GCM 包装 │
                                                            ▼
随机 256 位 DEK ───────────────────────────────────────> 被包装的 DEK
        │
        └── AES-256-GCM ──> 密码本载荷（JSON：分组 + 记录）
```

- **DEK / KEK 分离** — 数据用随机数据密钥（DEK）加密，DEK 再由主密码派生的密钥（KEK）包装；修改主密码只需重新包装 DEK。
- **AES-256-GCM** — 128 位认证标签，每次加密都使用新的随机 12 字节 IV，并用 AAD 把密文绑定到上下文。
- **指纹（可选）** — Android Keystore 中的 AES-256 密钥包装同一把 DEK；该密钥要求用户认证，验证指纹后 30 秒内可用。密钥不出安全硬件；新增指纹会让旧密钥永久失效，此时应用会提示改用主密码解锁。
- **原子写入** — 临时文件 + `fsync` + 重命名，避免断电产生半写文件。
- **完全离线** — 清单中没有 `INTERNET` 权限，`usesCleartextTraffic` 为 false。
- **内存清理** — DEK 只存在于内存，锁定时清零；密码 `CharArray` 用后擦除。

威胁模型：本应用保护设备上的静态数据；无法防御已被攻破的系统、带注入的 root 设备或键盘记录器。

## 环境要求

| 项目 | 版本 |
| --- | --- |
| Android | 8.0+（API 26），target API 35 |
| JDK | 17 或 21 |
| Gradle | 8.9（已含 wrapper） |
| Android Gradle Plugin | 8.7.3 |

## 编译

```bash
./gradlew :app:assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。发布版请先在 `app/build.gradle.kts` 中配置自己的签名。

## 使用

1. 安装 APK 并打开应用。
2. 设置主密码（至少 8 位）。主密码不可找回——忘记即无法解密，这是设计使然。
3. 添加记录：名称、账户、密码、可选子密码、备注、分组。
4. 可在「设置」中开启指纹解锁；随时可以关闭，主密码始终可用。

## 项目结构

```
app/src/main/java/com/localvault/passwordbook/
├── MainActivity.kt              # 单 Activity，生命周期与安全标记
├── VaultViewModel.kt            # 状态机、解锁与开启指纹流程
├── data/                        # 信封、载荷模型、原子文件存储
├── security/                    # PBKDF2 + AES-GCM、Keystore 包装、密码生成
└── ui/                          # Compose 页面（设置主密码、锁屏、列表、编辑、详情、分组、设置）
```

## 已知限制

- 指纹解锁依赖设备 Keystore，个别厂商系统存在兼容性问题；若绑定密钥失效，用主密码解锁后重新开启即可。
- 不支持云同步、导出与密码找回。
